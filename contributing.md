# Contribution Guidelines

Thank you for your interest in contributing to **awesome-garment-erp** — a curated list of garment factory ERP, production tracking, and apparel manufacturing software resources.

## Adding a New Entry

Please ensure your suggestion is:

* **Directly relevant** to garment factory ERP, production tracking, apparel manufacturing software, sewing-line execution systems, or related hardware/services.
* **Production-tested or actively maintained** — no abandoned or alpha-stage projects.
* **Clearly described** — name, link, and a brief one-line description of what it does.
* **Useful to a garment factory owner or production manager** — not just academic interest.

## Format

Each entry should follow this pattern:

```markdown
- [Project Name](https://link-to-project) — Short description (under 100 chars) explaining what it does and who it's for.
```

* Add new entries in alphabetical order within their section.
* Don't duplicate entries already on the list.
* Make sure the description ends with a period.

## Pull Request Process

1. Fork this repository.
2. Add your entry in the appropriate section of `README.md`.
3. Run a spell-check on your changes.
4. Open a pull request with a clear title (e.g., "Add [Project Name] to [Section Name]").
5. Explain in the PR body why this addition is useful to garment factory operators.

## Quality Bar

We curate this list — not every suggestion will be accepted. We prioritize:

* Tools that have shipped to real factories
* Open-source utilities with permissive licenses (MIT, Apache, CC0)
* Vendors with transparent pricing
* Educational resources from credible industry sources (AEPC, CMAI, Apparel Resources, etc.)

We will not accept:

* Affiliate or referral-coded links
* Self-promotional listings without industry relevance
* Tools that don't run or have been abandoned
* Spam, link farms, or paid promotion

## Code of Conduct

By participating in this project, you agree to abide by the [Code of Conduct](code-of-conduct.md).
